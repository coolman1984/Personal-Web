# الموقع الشخصي — كورسات الذكاء الاصطناعي

موقع شخصي عربي بالكامل (RTL) لـ**محمد فوزي لبيب** — مدرّب التحوّل بالذكاء
الاصطناعي وأتمتة المؤسسات.

**١١ كورس** (منهم **٢ ميني كورس**) على **٣ مستويات**، مبنية من برنامج تدريبي حقيقي من ٨ مستويات
متتابعة (من «مساعد شخصي» لـ«فريق رقمي ذكي») ومن خمسة أدلة عملية بالعربي.

**٦٤ صفحة** متولّدة مسبقًا · تصميم حديث · وبنية جاهزة للتوسّع.

---

## التشغيل السريع

```bash
npm install
npm run dev
```
افتح <http://localhost:3000>

**الموقع بيشتغل ١٠٠% من غير أي مفاتيح أو متغيّرات بيئة.**
الإعدادات الاختيارية (دفع، إيميل، تحليلات) موثّقة في `.env.example`.

## أول ٥ حاجات تغيّرها

| # | الملف | اللي تغيّره | ليه مستعجل |
|---|-------|--------------|-------------|
| ١ | `src/content/site.ts` | **الإيميل والتليفون والواتساب** | دلوقتي أرقام وهمية — الزائر مش هيوصلك |
| ٢ | `src/content/site.ts` | روابط السوشيال + رابط الموقع | احذف أي حساب مش موجود عندك |
| ٣ | `src/content/courses.ts` | الأسعار وتواريخ المجموعات | القيم الحالية تقديرية |
| ٤ | `src/content/testimonials.ts` | آراء متدربين حقيقيين بإذنهم | **فاضية عن قصد** — السكشن مخفي لحد ما تضيف |
| ٥ | `src/content/stats.ts` | أرقامك الحقيقية | رقم غلط بيهدّ الثقة أسرع ما بيبنيها |

بعد ما تغيّر الاسم أو الجملة، شغّل `npm run og` عشان صورة المشاركة تتحدّث.

## اللي جاهز في الموقع

- **الكورسات:** فلترة بالمستوى · بحث · ترتيب · منهج كامل بوحداته ومخرجاته
- **التحويل:** اختبار تحديد مستوى (٨ أسئلة) · فورم حجز · واتساب عائم · شريط CTA للموبايل
- **البحث:** لوحة أوامر بـ`Ctrl+K` بتدوّر في الكورسات والمقالات والمشاريع والصفحات
- **الدفع:** طبقة مجرّدة بـ٣ بوابات (وهمية شغّالة الآن · Stripe · Paymob) — تتفعّل بإضافة المفاتيح
- **الـAPI:** ٥ مسارات بتحقّق كامل من المدخلات وحماية من الطلبات المتكرّرة
- **SEO:** خريطة موقع · robots · بيانات منظّمة (٦ أنواع) · صورة مشاركة · PWA
- **الوصولية:** تنقّل كامل بالكيبورد · تباين AA · احترام تقليل الحركة

## النشر

### قبل ما ترفع — راجع الخمسة دول

1. **بياناتك الحقيقية** — دوّر على `// 👈 غيّر ده` في `src/content/` وغيّر كل
   اللي عليه العلامة دي (الاسم، التليفون، الإيميل، السوشيال، الأسعار، الآراء).
   أي رقم أو رأي مش حقيقي بيضرّ مصداقيتك.
2. **الآراء والأرقام** — لو لسه ما عندكش آراء متدربين حقيقية، سيب
   `src/content/testimonials.ts` فاضي؛ الموقع بيخفي السكشن لوحده.
3. **صورة المشاركة** — بعد ما تغيّر اسمك، اعمل `node scripts/generate-og.mjs`
   عشان `public/og-default.png` تتولّد من جديد باسمك.
4. **الفحص النهائي** — `npm run typecheck && npm run build` لازم الاتنين يعدّوا.
5. **الدفع** — سيب `features.payments` في `src/content/site.ts` على `false`
   لحد ما تربط بوابة دفع حقيقية. من غيرها التسجيل بيشتغل بنموذج تواصل عادي.

### الرفع على Vercel (الأسهل والمجاني للبداية)

1. ارفع الريبو على GitHub.
2. ادخل [vercel.com](https://vercel.com) → **Add New → Project** → اختار الريبو.
3. Vercel هيكتشف Next.js لوحده — ما تغيّرش أي إعداد بناء.
4. في **Environment Variables** ضيف على الأقل:
   `NEXT_PUBLIC_SITE_URL` = الدومين النهائي بتاعك (من غير `/` في الآخر).
5. **Deploy**. بعد أول نشر، روح **Settings → Domains** وارْبُط دومينك،
   وبعدين ارجع عدّل `NEXT_PUBLIC_SITE_URL` بيه واعمل **Redeploy**.

> ⚠️ `NEXT_PUBLIC_SITE_URL` مش رفاهية: خريطة الموقع، الروابط القانونية،
> وصور المشاركة على السوشيال كلها بتتبني منه. لو غلط، جوجل هيفهرس روابط غلط.

### متغيّرات البيئة

كلها موجودة بشرحها في [`.env.example`](./.env.example). محليًا انسخه لـ`.env.local`:

```bash
cp .env.example .env.local
```

| المتغيّر | إجباري؟ | بيعمل إيه |
|----------|---------|-----------|
| `NEXT_PUBLIC_SITE_URL` | ✅ **أيوه** | أساس كل الروابط المطلقة والـSEO |
| `RESEND_API_KEY` + `CONTACT_TO_EMAIL` | لا | يوصّلك رسائل نموذج التواصل على إيميلك |
| `MAILCHIMP_API_KEY` + `MAILCHIMP_AUDIENCE_ID` | لا | يحفظ مشتركي النشرة |
| `STRIPE_*` | لا | الدفع بالبطاقة عالميًا |
| `PAYMOB_*` | لا | الدفع في مصر |
| `NEXT_PUBLIC_GA_ID` / `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` | لا | التحليلات |

**من غير المفاتيح الاختيارية الموقع بيشتغل عادي** — الفورمات بتتحقّق من
البيانات وبترد برسالة نجاح، بس ما بتتخزّنش في حتة. اربط المفاتيح لما تحتاج.

⛔ **ممنوع** تحط أي مفتاح سرّي في الكود أو ترفعه على GitHub — كله في
متغيّرات البيئة بس.

### استضافات تانية

المشروع Next.js عادي، فبيشتغل على أي استضافة بتدعمه (Netlify، Cloudflare
Pages، أو سيرفر بتاعك بـ`npm run build && npm start`). محتاج Node 20 أو أحدث.

### بعد النشر

- اتأكد إن `your-domain.com/sitemap.xml` و`robots.txt` بيفتحوا.
- سجّل الموقع في [Google Search Console](https://search.google.com/search-console)
  وقدّم خريطة الموقع.
- جرّب مشاركة الرابط على واتساب أو لينكدإن وشوف صورة المشاركة ظاهرة صح.

التفاصيل الكاملة لخطوات التوسّع في [`docs/ROADMAP.md`](./docs/ROADMAP.md).
