# الموقع الشخصي — كورسات الذكاء الاصطناعي

موقع شخصي عربي بالكامل (RTL) لـ**محمد فوزي لبيب** — مدرّب التحوّل بالذكاء
الاصطناعي وأتمتة المؤسسات.

**٩ كورسات** على **٣ مستويات**، مبنية من برنامج تدريبي حقيقي من ٨ مستويات
متتابعة (من «مساعد شخصي» لـ«فريق رقمي ذكي») ومن خمسة أدلة عملية بالعربي.

**٦٠ صفحة** متولّدة مسبقًا · تصميم حديث · وبنية جاهزة للتوسّع.

---

## التشغيل السريع

```bash
npm install
npm run dev
```
افتح <http://localhost:3000>

**الموقع بيشتغل ١٠٠% من غير أي مفاتيح أو متغيّرات بيئة.**
الإعدادات الاختيارية (دفع، إيميل، تحليلات) موثّقة في `.env.example`.

## أول ٥ حاجات تغيّرها

| # | الملف | اللي تغيّره | ليه مستعجل |
|---|-------|--------------|-------------|
| ١ | `src/content/site.ts` | **الإيميل والتليفون والواتساب** | دلوقتي أرقام وهمية — الزائر مش هيوصلك |
| ٢ | `src/content/site.ts` | روابط السوشيال + رابط الموقع | احذف أي حساب مش موجود عندك |
| ٣ | `src/content/courses.ts` | الأسعار وتواريخ المجموعات | القيم الحالية تقديرية |
| ٤ | `src/content/testimonials.ts` | آراء متدربين حقيقيين بإذنهم | **فاضية عن قصد** — السكشن مخفي لحد ما تضيف |
| ٥ | `src/content/stats.ts` | أرقامك الحقيقية | رقم غلط بيهدّ الثقة أسرع ما بيبنيها |

كل مكان محتاج تعديل معلّم عليه `// 👈 غيّر ده` في الكود.
بعد ما تغيّر الاسم أو الجملة، شغّل `npm run og` عشان صورة المشاركة تتحدّث.

## اللي جاهز في الموقع

- **الكورسات:** فلترة بالمستوى · بحث · ترتيب · منهج كامل بوحداته ومخرجاته
- **التحويل:** اختبار تحديد مستوى (٨ أسئلة) · فورم حجز · واتساب عائم · شريط CTA للموبايل
- **البحث:** لوحة أوامر بـ`Ctrl+K` بتدوّر في الكورسات والمقالات والمشاريع والصفحات
- **الدفع:** طبقة مجرّدة بـ٣ بوابات (وهمية شغّالة الآن · Stripe · Paymob) — تتفعّل بإضافة المفاتيح
- **الـAPI:** ٥ مسارات بتحقّق كامل من المدخلات وحماية من الطلبات المتكرّرة
- **SEO:** خريطة موقع · robots · بيانات منظّمة (٦ أنواع) · صورة مشاركة · PWA
- **الوصولية:** تنقّل كامل بالكيبورد · تباين AA · احترام تقليل الحركة

## هيكل المشروع

```
src/
├── app/         الصفحات والمسارات (App Router)
├── components/  المكوّنات — ui / layout / sections / course / motion / shared
├── content/     🔑 كل النصوص والبيانات — المكان الوحيد للتعديل
├── lib/         الأدوات، SEO، الاستعلامات، الدفع
├── hooks/       الـhooks المخصّصة
└── types/       كل تعريفات الأنواع
docs/            الخطط والمواصفات الكاملة
```
