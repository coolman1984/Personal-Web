```
┌──────────────────────────────────────────────────────────┐
```

## 3. الاختيار التقني: ليه Supabase؟

**التوصية: Supabase** (قاعدة بيانات + مصادقة + تخزين ملفات في خدمة واحدة).

| البديل | ليه رفضناه |
|--------|-------------|
| قائمة إيميلات في ملف كود | صاحب الموقع هيضطر يعدّل كود ويعيد النشر مع كل متدرّب — مرهق ومعرّض للخطأ |
| Auth.js لوحده | بيحلّ الدخول بس، وهتحتاج قاعدة بيانات برضه بعد شهر |
| منصّة تعلّم جاهزة | بتفرض شكلها، وبتاخد نسبة من كل مبيعة، وبتكسر هوية الموقع |

**مميزات Supabase هنا تحديدًا:**
- الدخول بجوجل جاهز — يوم شغل واحد
- الرابط السحري بالإيميل جاهز كمان (مهم لناس الشركات — §5)
- الطبقة المجانية سخية (٥٠ ألف مستخدم نشط شهريًا)
- لما تيجي المرحلة ٢، قاعدة البيانات موجودة أصلًا
- **RLS** (أمان على مستوى الصف) = المتدرّب ما يقدرش يشوف بيانات غيره حتى لو حاول

## 4. نموذج البيانات

```sql
-- ═══ المتدربين ═══════════════════════════════════════════
-- Supabase بيعمل جدول auth.users تلقائيًا. ده جدول الملف الشخصي.
create table profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  email text unique not null,
  full_name text,
  phone text,
  created_at timestamptz default now()
);

-- ═══ الوصول للكورسات ═════════════════════════════════════
-- الجدول ده هو قلب النظام كله.
create table course_access (
  id uuid primary key default gen_random_uuid(),

  -- الإيميل هو المفتاح، مش user_id.
  -- السبب: بنفتح الوصول قبل ما الشخص يعمل حساب أصلًا.
  email text not null,
  course_slug text not null,

  -- إزاي اتفتح الوصول ده؟ مهم للمتابعة والمحاسبة
  granted_by text not null default 'manual',   -- manual | payment | gift
  payment_reference text,
  amount numeric(10,2),

  -- تاريخ انتهاء اختياري — للاشتراكات في المرحلة ٥
  expires_at timestamptz,

  note text,                                    -- ملاحظة لصاحب الموقع
  created_at timestamptz default now(),

  unique (email, course_slug)
);

create index on course_access (lower(email));

-- ═══ من هو المسؤول؟ ══════════════════════════════════════
create table admins (
  email text primary key,
  created_at timestamptz default now()
);
```

### 4.1 ليه الإيميل هو المفتاح مش `user_id`؟

ده أهم قرار في التصميم كله.

```
الترتيب اللي بيحصل فعلًا:
  ١) المتدرّب يدفع (واتساب / تحويل)
  ٢) صاحب الموقع يضيف إيميله في course_access   ← لسه مفيش حساب!
  ٣) المتدرّب يدخل بجوجل لأول مرة
  ٤) النظام يقارن إيميل حسابه بالجدول → يفتحله
```

لو ربطنا بـ`user_id`، كان لازم الشخص يعمل حساب **قبل** ما ندّيله الوصول —
وده مستحيل إداريًا.

### 6.1 شاشة إدارة الوصول — المواصفات

دي الشاشة اللي صاحب الموقع هيستخدمها كل يوم. لازم تكون **أبسط حاجة ممكنة**:

```
┌──────────────────────────────────────────────────────┐
│  فتح وصول جديد                                       │
│  ┌────────────────────┐ ┌──────────────────┐        │
│  │ الإيميل            │ │ الكورس        ▾  │        │
│  └────────────────────┘ └──────────────────┘        │
│  ┌────────────────────────────────────────┐         │
│  │ ملاحظة (اختياري) — دفع ٢٠٠٠ واتساب     │         │
│  └────────────────────────────────────────┘         │
│                                   [ افتح الوصول ]    │
├──────────────────────────────────────────────────────┤
│  الوصول المفتوح  (٢٣)                    🔍 بحث      │
│  ─────────────────────────────────────────────────   │
│  ahmed@gmail.com   أتمتة الإكسل   ١٥ سبتمبر  [سحب]  │
│  mona@company.com  العقل الثاني   ١٢ سبتمبر  [سحب]  │
└──────────────────────────────────────────────────────┘
```

**قواعد:**
- الإيميل بيتحوّل لحروف صغيرة قبل التخزين والمقارنة (`lower()`)
- لو الإيميل موجود بالفعل لنفس الكورس → رسالة واضحة، مش خطأ
- زرّ السحب بيسأل تأكيد قبل ما ينفّذ

## 7. الحماية — ٣ طبقات مش واحدة

الاعتماد على طبقة واحدة بس = ثغرة.

| الطبقة | فين | بتمنع إيه |
|--------|-----|-----------|
| **١ · Middleware** | `src/middleware.ts` | الدخول على `/my/*` و`/admin/*` بدون جلسة |
| **٢ · فحص في الصفحة** | `(protected)/my/[slug]/page.tsx` | فتح كورس **مش مفتوح ليك** حتى لو عندك حساب |
| **٣ · RLS في القاعدة** | سياسات Supabase | قراءة بيانات غيرك حتى لو اتحايلت على الطبقتين فوق |

```sql
-- الطبقة ٣ — إجبارية، مش اختيارية
alter table course_access enable row level security;

create policy "المتدرّب يشوف وصوله هو بس"
  on course_access for select
  using (lower(email) = lower(auth.jwt() ->> 'email'));

create policy "المسؤول يشوف كل حاجة"
  on course_access for all
  using (exists (
    select 1 from admins
    where lower(admins.email) = lower(auth.jwt() ->> 'email')
  ));
```

> ⚠️ **ممنوع** الاعتماد على إخفاء الروابط. أي محتوى مدفوع لازم يمرّ على
> الطبقات التلاتة.


**ولا سطر في منطقة المتدرّب بيتغيّر.** هي بتقرا من نفس الجدول.

**أ) في [Google Cloud Console](https://console.cloud.google.com):**
1. APIs & Services → Credentials → Create Credentials → OAuth client ID
2. Application type: **Web application**
3. Authorized redirect URI:
   ```
   https://kcuyctrchvfdjiyggkau.supabase.co/auth/v1/callback
   ```

4. خُد الـ**Client ID** والـ**Client Secret**

**ب) في لوحة Supabase → Authentication → Providers → Google:**

- **Site URL:** دومينك (أو `http://localhost:3000` للتجربة)

## 14. ⚠️ ملاحظة أمان على إعدادات المشروع

في إعدادات إنشاء المشروع، Supabase نفسها بتقول عن خيار
**«Automatically expose new tables»**:

> *We recommend disabling this to control access manually*

الخيار ده مفعّل عندك. **ده مش خطر دلوقتي** لأن:
1. خيار **«Enable automatic RLS»** مفعّل كمان، فأي جدول جديد بيتحمي تلقائيًا
2. الجدول اللي عليه RLS من غير سياسات **بيرفض كل حاجة** — مش بيسمح بكل حاجة
3. الهجرة بتاعتنا بتكتب سياسات صريحة لكل جدول

**بس خلّي بالك:** أي جدول جديد تضيفه بعد كده من لوحة Supabase مباشرة
هيتعرض على الـAPI. القاعدة البسيطة: **كل جدول جديد لازم يتعمله سياسات RLS
في نفس اللحظة**، أو تقفل الخيار ده من Settings → API.

## 15. جرّب إن كل حاجة شغّالة

بعد الأربع خطوات:

| # | التجربة | المتوقّع |
|---|---------|-----------|
| ١ | افتح `/login` واضغط جوجل | يوديك لجوجل ويرجّعك على `/my` |
| ٢ | افتح `/my` وإنت لسه ما اشتريتش | «لسه مفيش كورسات مفتوحة» |
| ٣ | افتح `/admin` قبل ما تضيف نفسك | ٤٠٤ |
| ٤ | ضيف نفسك في `admins` وافتح `/admin` | اللوحة تفتح |
| ٥ | افتح وصول لإيميلك من `/admin/access` | يظهر في القائمة |
| ٦ | ارجع لـ`/my` | الكورس ظاهر |
| ٧ | افتح `/my/<كورس-مش-مفتوح>` بإيدك | ٤٠٤ |
| ٨ | افتح صفحة الكورس العامة | صندوق السعر بقى «إنت مشترك» |

**الاختبار رقم ٧ هو الأهم** — هو اللي بيثبت إن الحماية شغّالة فعلًا.
